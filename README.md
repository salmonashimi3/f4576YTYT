# HORNET STRIKE ✈️

브라우저에서 실행되는 DCS 스타일 3D 전투기 시뮬레이터. three.js 로 제작되었으며, 별도 설치 없이 웹페이지 하나로 동작합니다.

실제 위성(NASA Blue Marble) 지도 위에서 전 세계를 비행하고, 항공모함 착함·폭격·도그파이트·착륙 연습 등을 즐길 수 있습니다.

## 🎮 실행 방법

### 1) 그냥 열기 (로컬)
브라우저 보안 정책(ES module) 때문에 `index.html` 을 더블클릭하면 안 되고, 간단한 로컬 서버가 필요합니다.

```bash
# 이 폴더 안에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 2) GitHub Pages 로 배포 (추천)
1. 이 폴더 전체를 GitHub 저장소에 업로드 (push)
2. 저장소 **Settings → Pages** 로 이동
3. **Source** 를 `Deploy from a branch` → 브랜치 `main` / 폴더 `/ (root)` 선택 후 Save
4. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 실행됩니다

> `.nojekyll` 파일이 포함되어 있어 GitHub Pages 가 파일을 그대로 서빙합니다.

- **F/A-18E** 슈퍼호넷
- **F-14** 톰캣 (가변익 — 고속에서 날개 후퇴)
